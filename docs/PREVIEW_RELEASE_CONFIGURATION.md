# Preview and GitHub Release Configuration

## Vercel

- Root Directory: `frontend`
- Framework preset: Next.js
- Install: `npm ci`
- Build: `npm run build`
- Output: generated by Next.js
- Production branch: `master`
- Preview branch: `feature/social-media-studio-v2`

Do not point Preview at the production Supabase project unless explicitly authorized.

## Required Preview variables

Public variables:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
- `NEXT_PUBLIC_API_BASE_URL`, only if FastAPI compatibility is deployed
- `NEXT_PUBLIC_ADSENSE_ENABLED=false`
- `NEXT_PUBLIC_ADSTERRA_ENABLED=false`
- `NEXT_PUBLIC_BRAND_LOGO_URL`, optional

Server variables:

- `SUPABASE_URL`
- `SUPABASE_PUBLISHABLE_KEY`
- `SUPABASE_SECRET_KEY`
- `BACKEND_PUBLIC_URL`, only for actual FastAPI proxy compatibility
- `ADMIN_USER_IDS`
- `ADMIN_EMAILS`
- `OAUTH_STATE_SECRET`
- `OAUTH_TOKEN_ENCRYPTION_KEY`
- `TIKTOK_CLIENT_KEY`
- `TIKTOK_CLIENT_SECRET`
- `TIKTOK_REDIRECT_URI`
- `IMAGE_PROXY_ALLOWED_HOSTS`
- `ADS_TXT_LINES`
- `NEXT_PUBLIC_GA4_MEASUREMENT_ID`, optional

Never place service role, OAuth secret or encryption key in a `NEXT_PUBLIC_*` variable.

## GitHub Actions secrets

Required by scheduled publications:

- `SUPABASE_URL`
- `SUPABASE_SECRET_KEY`

Artifact processing additionally:

- `ANTHROPIC_API_KEY`

Media processing:

- `RUNTIME_BASE_URL`

Discovery and scraper:

- `SCRAPER_SOURCES`

Supabase values must point to staging while Preview is under validation.

## Publication procedure

No commit or push is performed by this repository session.

After Preview approval:

1. Run `npm ci`.
2. Run `npx tsc --noEmit`.
3. Run `npm run lint`.
4. Run `npm test`.
5. Run `npm run build`.
6. Configure Preview environment variables.
7. Create a GitHub Preview deployment only after external configuration.
8. Run workflow `workflow_dispatch` operations manually in staging.
9. Open a PR from `feature/social-media-studio-v2` to `master`.
10. Merge only after Preview and staging evidence are approved.
